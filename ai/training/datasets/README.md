# Recorded datasets

`GameRecorder.save()` writes its `.jsonl` recordings here, and this is the
folder the Python trainer reads by default:

    cd ai/python
    python -m mtgai.train            # defaults to ../training/datasets

The `.jsonl` files themselves are git-ignored (`datasets/` in `.gitignore`) —
they are large and regenerated by running matches. The empty `.gdignore` keeps
the Godot editor from scanning and re-importing them on every rescan.
